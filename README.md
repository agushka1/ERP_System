# RespectSys ERP — Корпоративная система благодарностей и мерч-магазина

Современная высоконадежная ERP-система для автоматизации корпоративной культуры, обмена монетами благодарности между сотрудниками и складского учета мерча. Проект разработан на фреймворке **Django** с использованием базы данных **PostgreSQL** и стилизован в премиальном темном кибер-дизайне.

## 🚀 Основной функционал

*   **ACID Финансовые транзакции:** Переводы валюты благодарности между коллегами намертво защищены на уровне базы данных (`select_for_update`) от дублирования и гонки данных (Race Conditions).
*   **SOLID & DRY Архитектура:** Бизнес-логика полностью изолирована в сервисный слой (`services.py`), а навигация и уведомления используют общие переиспользуемые шаблоны.
*   **Комплексная Корзина Покупок:** Возможность набирать товары со склада и оплачивать их единым чеком внутри атомарной транзакции базы данных.
*   **Складской CRM-учет:** Раздельные админ-панели для управления балансами сотрудников, добавления товаров с фото и поэтапного отслеживания статусов заказов (*Оплачен -> Ожидает получения -> Выдан*).
*   **Премиальный тёмный дизайн:** Адаптивный и современный Web3/SaaS-интерфейс в тёмно-серых, синих и фиолетовых неоновых тонах.

## 🛠️ Инструкция по запуску проекта

Для запуска проекта на локальной машине проверяющему достаточно склонировать репозиторий и выполнить следующие 5 простых шагов в терминале:

### 1. Создание и активация виртуального окружения
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate
```

### 2. Установка необходимых зависимостей
```bash
pip install -r requirements.txt
```

### 3. Применение миграций (создание структуры таблиц)
```bash
python manage.py migrate
```

### 4. Восстановление базы данных (Загрузка сотрудников, монет и мерча)
*В корень проекта уже вшит готовый дамп базы данных со всеми тестовыми кошельками и товарами на складе.*
```bash
python manage.py loaddata db_backup.json
```

### 5. Запуск локального сервера разработки
```bash
python manage.py runserver
```

После этого проект станет доступен в браузере по адресу: **`http://127.0.0`**
